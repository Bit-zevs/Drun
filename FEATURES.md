# Возможности Drun

## Общение

- Личный чат с ботом в Telegram для настроенного владельца.
- Интерактивный чат в консоли через `drun chat` и разовые запросы через `drun ask`.
- Общая история и очередь задач для Telegram и консоли.
- Форматирование ответов в Telegram: жирный текст, курсив, ссылки, код и разбиение длинных сообщений.
- Смена тона через `/style`: мемный, нейтральный или свой по текстовому описанию. Выбор сохраняется после перезапуска и действует в обоих интерфейсах.

## Инструменты и навыки

- Просмотр дерева рабочей папки, чтение и запись файлов в `workspace/`.
- Чтение корневых и вложенных инструкций `AGENTS.md` с учётом расположения файла.
- Обнаружение и загрузка навыков из `SKILL.md`. В комплекте есть `daily-brief` для обзора календарей.
- Выполнение команд Bash и PowerShell 7 в отдельном Docker-контейнере без сети, с ограничениями времени и ресурсов. Рабочая папка доступна контейнеру для чтения.
- Веб-поиск через Brave Search API со ссылками на результаты.
- Разовые напоминания с доставкой в Telegram. Наступившие напоминания можно посмотреть через `drun reminders`.
- Чтение личного календаря и внешнего расписания по ссылке iCalendar или из файла `.ics`. Учитываются повторяющиеся события и часовой пояс.
- Чтение открытых задач GitHub. Поддерживаются публичные репозитории и закрытые при наличии токена с доступом.
- Подключение инструментов MCP-серверов через Streamable HTTP.

## Модели, память и контроль

- Локальная Qwen3 8B для ответов и Qwen3 Embedding 0.6B для памяти. Обе запускаются через Ollama, с поддержкой CPU и NVIDIA GPU.
- LiteLLM как единый шлюз для чата, свёртки истории и эмбеддингов. Ключ облачной модели для работы агента не требуется.
- Самописный цикл нативных вызовов инструментов. Модель запрашивает действие, ядро исполняет его и возвращает результат в диалог.
- Сохранение диалога в SQLite. Старые сообщения сворачиваются в резюме по мере заполнения контекста.
- Долговременная память для фактов и предпочтений, которые попросили запомнить. Поиск по смыслу через эмбеддинги.
- Бюджет токенов, просмотр расхода через `drun usage` и веб-дашборд.
- Структурированные JSON-логи с идентификаторами задач и опциональный экспорт трассировок OpenTelemetry.
